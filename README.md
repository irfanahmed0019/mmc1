# MakeMyCut

Barber appointment booking: find trusted barbers, compare services and book a haircut in seconds.

## Features

- Customer sign in and appointment booking
- Salon sign in and a salon dashboard
- Reviews
- Password reset

## Tech stack

- React and TypeScript with Vite
- Tailwind CSS and shadcn/ui
- Supabase for auth and data
- TanStack Query and React Router

The main repository for this project is [makemycut](https://github.com/irfanahmed0019/makemycut).

## Run locally

```sh
npm install
npm run dev
```

Add your Supabase URL and anon key to a local `.env` file first.
